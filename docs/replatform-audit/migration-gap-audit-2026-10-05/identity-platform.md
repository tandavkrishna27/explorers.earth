## Shared root causes and repair ordering

1. Canonical authority is implemented centrally, while some retained consumers still interpret an account UUID as Strapi user identity and require obsolete GraphQL/bearer authority. Navigation/settings and analytics share this **migration boundary**, but the exact network first cause is only established for the saved wrong-subject fixtures, not universally. `src/main.tsx:21–34` strips credentials and uses canonical `/graphql` with credentials omitted; inspected canonical app has no GraphQL mount. A fixture's owner-cookie recognition cannot prove a production facade.
2. Acceptance is split between canonical local real-backend slices and legacy hosted fixtures/protocols. Port retained behavioral assertions to canonical cookie/account/revision/recovery flows; retain foreign-subject denial, egress guards, A→B→A fencing and original failure evidence. Map every retained old assertion before retiring its protocol assertion. Adding get-session alone leaves the separate lifecycle protocol mismatch.
3. Backend availability is being confused with frontend completion: analytics summary exists but dashboard still needs an account selector and cookie client; media routes exist but providers remain unverified; FAQ/legal require seed content and adapters. Close those chains individually rather than reporting the backend route as UI parity.

Minimal authorized repair sequence for the parent plan: first finish canonical navigation/settings authority and targeted subject/transport acceptance; next replace legacy auth/lifecycle fixtures using canonical harness while mapping retained behaviors; then consume canonical dashboard summary and qualify counts/consent; deliver reviewed localized reference/legal/help data with a narrow typed content API and existing screens; finally run bounded affected local/hosted acceptance and real provider smoke under existing ownership/configuration. These are recommendations, not repairs or permission to execute. Do not weaken guards, increase timeouts or invent a canonical-to-Strapi identity map.
