# WP2: Publish pill, phone bottom add button, publish nudge (implementation plan)

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking. TDD: every step that adds code has its failing test written and run first.

**Goal:** Ship three shared, unwired dashboard controls that WP3A, WP3B, WP6 and WP9 adopt: the one publish pill (GL-08, CAT-02, LP-01, LP-10, PRIV-06, GD-21), the phone full-width sticky bottom add button (GL-08, CAT-03), and the publish nudge (GL-04, OWN-02) as a hook plus its dialog. CAT-08 (card ⋯ menu on phones) reuses `publishPillOptions` exported here; the card itself belongs to WP3A.

**Architecture:** Presentational components under `explorers-earth/src/components/controls/` and one router-state hook under `explorers-earth/src/hooks/`. No API calls: consumers pass `onChange` / `onPublish` that call the existing visibility commands. The pill is a hand-built WAI-ARIA menu button (no new dependency). The bottom button is phone-only via the existing `useDeviceDetection` hook and listens to `window` scroll (the phone layout scrolls the window). The nudge rule is a pure function (`decidePublishNudge`) covered by a rule table; the hook adds router state, per-list session memory in `sessionStorage`, and an explicit `leave()` guard (the app uses `BrowserRouter`, so `useBlocker` is not available).

**Tech Stack:** React 18.3, TypeScript strict (`noUnusedLocals`), Tailwind 3.4.19 (logical `ms-/ps-/end-` utilities for RTL), react-router-dom 7, react-i18next, sonner, Vitest 4 + Testing Library 16 + user-event 14 (jsdom).

**Base:** branch from current `main` (reference checkout verified at `8063651c`). Branch name: `claude/dash-wp2-controls`. One PR, merge commit only.

**Merge position (orchestrator ruling):** Wave 1 order is **WPCI → WP1 → WP2 → WP3B → WP3A → WP4 → WP5**; the later merger resolves conflicts. WP2 is **third**: before merging, rebase over `main` with WPCI and WP1 merged and resolve any conflict (expected only in the shared i18n files: re-run the Task 1 insertion script, never hand-merge). WP3B, WP3A, WP4 and WP5 rebase over WP2. If WP1 has set a CSS variable for the phone bottom nav height (`--dashboard-bottom-nav-height` on the phone layout root), `BottomAddButton` uses it via `var(--dashboard-bottom-nav-height, 64px)` with no code change; at rebase, check `grep -rn "dashboard-bottom-nav-height" explorers-earth/src` and, if WP1 named the variable differently, rename the reference in `BottomAddButton.tsx` and its test to WP1's name. `.github/workflows/test.yml` is append-only for WP2 (ruling R4, WPCI owns it); WP2 appends nothing (unit tests run in the existing frontend lane).

## Verified against main

Reference checkout `.claude/worktrees/wave1-main-ref/` at `8063651c`:

1. **No Radix dropdown/menu primitive.** `explorers-earth/package.json` L38-42 lists only `@radix-ui/react-accordion`, `-label`, `-slot`, `-toast`, `-tooltip`. `components/ui/Dropdown.tsx` (L1-50) is a combobox for profile categories, not a menu button. 2. **No Storybook.** No `.storybook/` and no `*.stories.tsx` anywhere under `explorers-earth/src`; no storybook script in `package.json` L13-33. The spec's "their tests and stories" is satisfied by tests only; adding Storybook would touch the unowned `package.json`/lockfile.

4. **Router:** `App.tsx` L1/L16 uses `BrowserRouter`, not a data router, so `useBlocker` is unavailable. ```js
// Inserts en.json's dashboard.wp2 block (English fallback, as sync-i18n would) into every
// other resource file WITHOUT re-sorting or re-formatting the rest of the file.
import fs from "node:fs";
import path from "node:path";

const dir = process.argv[2];
if (!dir) throw new Error("usage: node add-wp2-i18n.mjs <resources dir>");
const strip = (s) => s.replace(/^﻿/, "");
const en = JSON.parse(strip(fs.readFileSync(path.join(dir, "en.json"), "utf8")));
const block = en.dashboard && en.dashboard.wp2;
if (!block) throw new Error("add dashboard.wp2 to en.json first");

let changed = 0;
for (const file of fs.readdirSync(dir)) {
  if (!file.endsWith(".json") || file === "en.json") continue;
  const target = path.join(dir, file);
  const raw = fs.readFileSync(target, "utf8");
  const eol = raw.includes("\r\n") ? "\r\n" : "\n";
  const data = JSON.parse(strip(raw));
  if (!data.dashboard || typeof data.dashboard !== "object") throw new Error(file + " has no dashboard object");
  if (data.dashboard.wp2) continue;
  const before = JSON.stringify(data, null, 2).split("\n").join(eol) + eol;
  if (before !== strip(raw)) throw new Error(file + " does not round-trip; insert by hand");
  data.dashboard.wp2 = block;
  fs.writeFileSync(target, JSON.stringify(data, null, 2).split("\n").join(eol) + eol, "utf8");
  changed += 1;
}
console.log("inserted dashboard.wp2 into " + changed + " files");
```

// explorers-earth/src/components/controls/PublishPill.tsx
import { useCallback, useEffect, useId, useRef, useState, type KeyboardEvent as ReactKeyboardEvent } from "react";
import { useTranslation } from "react-i18next";
import { toast } from "sonner";

export type CategoryPublishValue = "public" | "hidden";
export type ListPublishValue = "draft" | "public";
export type PublishPillValue = CategoryPublishValue | ListPublishValue | "private";
export type PublishPillKind = "category" | "list" | "guide";

interface PublishPillCommonProps {
  /** Disables the pill (e.g. sample lists). It stays focusable and announces `disabledReason`. */
  disabled?: boolean;
  disabledReason?: string;
  className?: string;
}

export interface CategoryPublishPillProps extends PublishPillCommonProps {
  kind: "category";
  value: CategoryPublishValue;
  onChange: (next: CategoryPublishValue) => void | Promise<void>;
  /** Shown in the Public explanation: "Movies shows on your profile". */
  categoryName?: string;
}

export interface ListPublishPillProps extends PublishPillCommonProps {
  kind: "list" | "guide";
  value: ListPublishValue;
  /** Shows the disabled "Private (coming soon)" row (PRIV-06). Defaults to true. */
  privateComingSoon?: boolean;
  onChange: (next: ListPublishValue) => void | Promise<void>;
}

export type PublishPillProps = CategoryPublishPillProps | ListPublishPillProps;

export interface PublishPillOption {
  value: PublishPillValue;
  icon: string;
  comingSoon: boolean;
}

export const PUBLISH_PILL_ICONS: Record<PublishPillValue, string> = {
  public: "🌐",
  hidden: "🔒",
  draft: "✎",
  private: "👥",
};

/** The menu rows per kind. Also used by WP3A's phone card ⋯ menu (CAT-08) so both offer the same options. */
export function publishPillOptions(kind: PublishPillKind, privateComingSoon: boolean): PublishPillOption[] {
  if (kind === "category") {
    return [
      { value: "public", icon: PUBLISH_PILL_ICONS.public, comingSoon: false },
      { value: "hidden", icon: PUBLISH_PILL_ICONS.hidden, comingSoon: false },
    ];
  }
  const options: PublishPillOption[] = [
    { value: "draft", icon: PUBLISH_PILL_ICONS.draft, comingSoon: false },
    { value: "public", icon: PUBLISH_PILL_ICONS.public, comingSoon: false },
  ];
  if (privateComingSoon) options.push({ value: "private", icon: PUBLISH_PILL_ICONS.private, comingSoon: true });
  return options;
}

function explainKey(kind: PublishPillKind, value: PublishPillValue, hasCategoryName: boolean): string {
  if (kind === "category") {
    if (value === "hidden") return "dashboard.wp2.pill.explain.categoryHidden";
    return hasCategoryName ? "dashboard.wp2.pill.explain.categoryPublic" : "dashboard.wp2.pill.explain.categoryPublicGeneric";
  }
  if (value === "draft") return "dashboard.wp2.pill.explain.listDraft";
  if (value === "public") return "dashboard.wp2.pill.explain.listPublic";
  return "dashboard.wp2.pill.explain.listPrivate";
}

const PILL_SHELL =
  "inline-flex min-h-[44px] items-center gap-1.5 whitespace-nowrap rounded-full border px-3 py-1.5 font-poppins text-[12.5px] transition-colors focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[#60a5fa]";

/**
 * GL-08: the one publish pill for category, list and guide pages (header, top right).
 * A WAI-ARIA menu button: the button announces "Visibility: <state>", the menu holds
 * menuitemradio rows with the current one checked. The pill toasts on success; the
 * consumer's command surfaces its own errors.
 */
export function PublishPill(props: PublishPillProps) {
  const { t } = useTranslation();
  const { kind, value, disabled = false, disabledReason, className = "" } = props;
  const privateComingSoon = props.kind === "category" ? false : props.privateComingSoon ?? true;
  const categoryName = props.kind === "category" ? props.categoryName : undefined;
  const options = publishPillOptions(kind, privateComingSoon);

  const [open, setOpen] = useState(false);
  const [activeIndex, setActiveIndex] = useState(0);
  const [pending, setPending] = useState(false);
  const rootRef = useRef<HTMLDivElement>(null);
  const buttonRef = useRef<HTMLButtonElement>(null);
  const itemRefs = useRef<Array<HTMLDivElement | null>>([]);
  const baseId = useId();
  const buttonId = `${baseId}-button`;
  const menuId = `${baseId}-menu`;
  const reasonId = `${baseId}-reason`;
  const stateName = t(`dashboard.wp2.pill.state.${value}`);
  const inert = disabled || pending;

  const close = useCallback((returnFocus: boolean) => {
    setOpen(false);
    if (returnFocus) buttonRef.current?.focus();
  }, []);

  const openMenu = () => {
    if (inert) return;
    const current = options.findIndex((option) => option.value === value);
    setActiveIndex(current >= 0 ? current : 0);
    setOpen(true);
  };

  useEffect(() => {
    if (open) itemRefs.current[activeIndex]?.focus();
  }, [open, activeIndex]);

  useEffect(() => {
    if (!open) return;
    const onMouseDown = (event: MouseEvent) => {
      if (!rootRef.current?.contains(event.target as Node)) close(false);
    };
    document.addEventListener("mousedown", onMouseDown);
    return () => document.removeEventListener("mousedown", onMouseDown);
  }, [open, close]);

  const select = async (option: PublishPillOption) => {
    if (option.comingSoon) return;
    close(true);
    if (option.value === value) return;
    setPending(true);
    try {
      await (props.onChange as (next: PublishPillValue) => void | Promise<void>)(option.value);
      toast.success(t(`dashboard.wp2.pill.toast.${option.value}`));
    } catch {
      // The consumer's command shows its own error; the pill stays on the old value.
    } finally {
      setPending(false);
    }
  };

  const onMenuKeyDown = (event: ReactKeyboardEvent<HTMLDivElement>) => {
    const last = options.length - 1;
    switch (event.key) {
      case "ArrowDown":
        event.preventDefault();
        setActiveIndex((index) => (index >= last ? 0 : index + 1));
        break;
      case "ArrowUp":
        event.preventDefault();
        setActiveIndex((index) => (index <= 0 ? last : index - 1));
        break;
      case "Home":
        event.preventDefault();
        setActiveIndex(0);
        break;
      case "End":
        event.preventDefault();
        setActiveIndex(last);
        break;
      case "Enter":
      case " ":
        event.preventDefault();
        void select(options[activeIndex]);
        break;
      case "Escape":
        event.preventDefault();
        close(true);
        break;
      case "Tab":
        close(false);
        break;
      default:
        break;
    }
  };

  const tone =
    value === "public"
      ? "border-emerald-500/50 bg-emerald-500/10 text-emerald-300"
      : "border-white/[0.18] bg-[#0e1218] text-gray-200";

  return (
    <div ref={rootRef} className={`relative inline-flex ${className}`}>
      <button
        ref={buttonRef}
        id={buttonId}
        type="button"
        aria-haspopup="menu"
        aria-expanded={open}
        aria-controls={open ? menuId : undefined}
        aria-label={t("dashboard.wp2.pill.buttonLabel", { state: stateName })}
        aria-disabled={disabled || undefined}
        aria-busy={pending || undefined}
        aria-describedby={disabled && disabledReason ? reasonId : undefined}
        title={disabled ? disabledReason : undefined}
        data-kind={kind}
        data-value={value}
        onClick={() => (open ? close(false) : openMenu())}
        onKeyDown={(event) => {
          if (!open && (event.key === "ArrowDown" || event.key === "ArrowUp")) {
            event.preventDefault();
            openMenu();
          }
        }}
        className={`${PILL_SHELL} ${tone} ${inert ? "cursor-default opacity-60" : "cursor-pointer"}`}
      >
        <span aria-hidden="true">{PUBLISH_PILL_ICONS[value]}</span>
        <span>{stateName}</span>
        <span aria-hidden="true">▾</span>
      </button>
      {disabled && disabledReason ? (
        <span id={reasonId} className="sr-only">
          {disabledReason}
        </span>
      ) : null}
      {open ? (
        <div
          id={menuId}
          role="menu"
          aria-labelledby={buttonId}
          onKeyDown={onMenuKeyDown}
          className="absolute end-0 top-[calc(100%+6px)] z-[60] grid min-w-[230px] rounded-xl border border-white/[0.09] bg-[#1f2430] p-1 text-start text-[#f9fafb] shadow-2xl"
        >
          {options.map((option, index) => {
            const checked = option.value === value;
            return (
              <div
                key={option.value}
                ref={(node) => {
                  itemRefs.current[index] = node;
                }}
                role="menuitemradio"
                aria-checked={checked}
                aria-disabled={option.comingSoon || undefined}
                tabIndex={-1}
                onClick={() => void select(option)}
                onMouseEnter={() => setActiveIndex(index)}
                className={`grid min-h-[44px] gap-0.5 rounded-lg px-2.5 py-2 text-[12.5px] outline-none hover:bg-white/[0.06] focus:bg-white/[0.06] ${option.comingSoon ? "cursor-default opacity-55" : "cursor-pointer"}`}
              >
                <span>
                  <span aria-hidden="true" className="inline-block w-3.5 text-[#60a5fa]">
                    {checked ? "✓" : ""}
                  </span>
                  <span aria-hidden="true">{option.icon} </span>
                  {t(`dashboard.wp2.pill.state.${option.value}`)}
                  {option.comingSoon ? (
                    <span className="ms-1.5 rounded-full bg-yellow-400/15 px-1.5 text-[9px] text-yellow-400">
                      {t("dashboard.wp2.pill.comingSoon")}
                    </span>
                  ) : null}
                </span>
                <small className="ps-3.5 text-[11px] text-[#8b93a1]">
                  {t(explainKey(kind, option.value, Boolean(categoryName)), { category: categoryName })}
                </small>
              </div>
            );
          })}
        </div>
      ) : null}
    </div>
  );
}

export default PublishPill;
```

// explorers-earth/src/hooks/usePublishNudge.ts
export type ListPublishStatus = "draft" | "public";
export type PublishNudgeTrigger = "itemAdded" | "leaving";
export type PublishNudgeReason = "reachedThree" | "leaving";

export interface PublishNudgeInput {
  trigger: PublishNudgeTrigger;
  itemCount: number;
  status: ListPublishStatus;
  /** "Not now" was chosen for this list in this session. */
  dismissed: boolean;
  offeredAtThree: boolean;
  offeredOnLeave: boolean;
}

/** GL-04 / OWN-02: when to offer publishing a list. Pure so the rule table pins it. */
export function decidePublishNudge(input: PublishNudgeInput): PublishNudgeReason | null {
  if (input.status !== "draft" || input.itemCount <= 0 || input.dismissed) return null;
  if (input.trigger === "leaving") return input.offeredOnLeave ? null : "leaving";
  if (input.itemCount >= 3 && !input.offeredAtThree) return "reachedThree";
  return null;
}
```

const ROUTER_STATE_KEY = "publishNudge";
const SESSION_KEY = "explorers.publishNudge.v1";

export interface PublishNudgeRouterState {
  listId: string;
  trigger: "itemAdded";
}

/** Router state the add-item flow puts on its navigate back to the list page. */
export function publishNudgeRouterState(listId: string): { publishNudge: PublishNudgeRouterState } {
  return { [ROUTER_STATE_KEY]: { listId, trigger: "itemAdded" } } as { publishNudge: PublishNudgeRouterState };
}

interface ListNudgeRecord {
  dismissed?: boolean;
  offeredAtThree?: boolean;
  offeredOnLeave?: boolean;
}

function readAll(): Record<string, ListNudgeRecord> {
  try {
    const raw = window.sessionStorage.getItem(SESSION_KEY);
    const parsed: unknown = raw ? JSON.parse(raw) : {};
    return parsed && typeof parsed === "object" ? (parsed as Record<string, ListNudgeRecord>) : {};
  } catch {
    return {};
  }
}

function readRecord(listId: string): ListNudgeRecord {
  return readAll()[listId] ?? {};
}

function writeRecord(listId: string, patch: ListNudgeRecord): void {
  try {
    const all = readAll();
    all[listId] = { ...all[listId], ...patch };
    window.sessionStorage.setItem(SESSION_KEY, JSON.stringify(all));
  } catch {
    // Storage unavailable (private mode): the nudge may repeat this session, never crash.
  }
}

function inputFor(
  listId: string,
  trigger: PublishNudgeTrigger,
  itemCount: number,
  status: ListPublishStatus,
): PublishNudgeInput {
  const record = readRecord(listId);
  return {
    trigger,
    itemCount,
    status,
    dismissed: Boolean(record.dismissed),
    offeredAtThree: Boolean(record.offeredAtThree),
    offeredOnLeave: Boolean(record.offeredOnLeave),
  };
}

export interface PublishNudgeController {
  open: boolean;
  reason: PublishNudgeReason | null;
  /** "Not now": suppress for this list for the session, then continue any pending leave. */
  notNow: () => void;
  /** Close after the consumer published (or gave up), then continue any pending leave. */
  close: () => void;
  /** Wrap the list page's Back: runs `proceed` now, or after the nudge is answered. */
  leave: (proceed: () => void) => void;
}

/**
 * GL-04: one publish nudge for every category. Offers after the 3rd item (router state from
 * the add flow) or when leaving a draft list with items; never on an empty list; "Not now"
 * suppresses it per list per session. Pass `listId = null` until the list read is fresh.
 */
export function usePublishNudge(
  listId: string | null | undefined,
  itemCount: number,
  status: ListPublishStatus,
): PublishNudgeController {
  const location = useLocation();
  const navigate = useNavigate();
  const [reason, setReason] = useState<PublishNudgeReason | null>(null);
  const pendingLeave = useRef<(() => void) | null>(null);

  useEffect(() => {
    const state = location.state as Record<string, unknown> | null;
    const trigger = state?.[ROUTER_STATE_KEY] as PublishNudgeRouterState | undefined;
    if (!listId || !trigger || trigger.listId !== listId) return;
    const rest = Object.fromEntries(Object.entries(state ?? {}).filter(([key]) => key !== ROUTER_STATE_KEY));
    navigate(
      { pathname: location.pathname, search: location.search, hash: location.hash },
      { replace: true, state: Object.keys(rest).length > 0 ? rest : null },
    );
    if (decidePublishNudge(inputFor(listId, "itemAdded", itemCount, status)) === "reachedThree") {
      writeRecord(listId, { offeredAtThree: true });
      setReason("reachedThree");
    }
  }, [location.state, location.pathname, location.search, location.hash, listId, itemCount, status, navigate]);

  const finish = useCallback(() => {
    setReason(null);
    const proceed = pendingLeave.current;
    pendingLeave.current = null;
    proceed?.();
  }, []);

  const notNow = useCallback(() => {
    if (listId) writeRecord(listId, { dismissed: true });
    finish();
  }, [listId, finish]);

  const leave = useCallback(
    (proceed: () => void) => {
      if (!listId || decidePublishNudge(inputFor(listId, "leaving", itemCount, status)) !== "leaving") {
        proceed();
        return;
      }
      writeRecord(listId, { offeredOnLeave: true });
      pendingLeave.current = proceed;
      setReason("leaving");
    },
    [listId, itemCount, status],
  );

  return { open: reason !== null, reason, notNow, close: finish, leave };
}
```

// explorers-earth/src/components/controls/PublishNudge.tsx
import { AnimatePresence, motion } from "framer-motion";
import { Loader2 } from "lucide-react";
import { useTranslation } from "react-i18next";
import DialogPanel from "../ui/DialogPanel";
import type { PublishNudgeReason } from "../../hooks/usePublishNudge";

export interface PublishNudgeProps {
  open: boolean;
  reason: PublishNudgeReason | null;
  kind: "list" | "guide";
  listName: string;
  /** True while the consumer's publish command runs. */
  busy?: boolean;
  onPublish: () => void | Promise<void>;
  /** "Not now", Escape and the backdrop all land here. */
  onNotNow: () => void;
}

const NAME_TOKEN = "\u0000name\u0000";

/** GL-04 nudge dialog, driven by usePublishNudge. Built on DialogPanel (XC-02 overlay audit). */
export function PublishNudge({ open, reason, kind, listName, busy = false, onPublish, onNotNow }: PublishNudgeProps) {
  const { t } = useTranslation();
  if (!open || !reason) return null;

  const body = t(`dashboard.wp2.nudge.body.${reason}`, { name: NAME_TOKEN });
  const [before, after = ""] = body.split(NAME_TOKEN);

  return (
    <AnimatePresence>
      <DialogPanel
        onClose={busy ? () => {} : onNotNow}
        onClick={busy ? undefined : onNotNow}
        className="fixed inset-0 z-[160] flex items-end justify-center bg-black/70 p-4 backdrop-blur-sm sm:items-center"
      >
        <motion.div
          className="relative w-full max-w-md rounded-xl border border-dashboard-border bg-dashboard-sidebar p-6 font-poppins shadow-2xl"
          initial={{ scale: 0.95, opacity: 0 }}
          animate={{ scale: 1, opacity: 1 }}
          exit={{ scale: 0.95, opacity: 0 }}
          onClick={(event) => event.stopPropagation()}
        >
          <h3 className="mb-2 text-lg font-bold text-dashboard">{t(`dashboard.wp2.nudge.title.${kind}`)}</h3>
          <p className="mb-6 text-sm leading-relaxed text-dashboard-muted">
            {before}
            <span title={listName} className="line-clamp-2 inline font-semibold text-dashboard [overflow-wrap:anywhere]">
              {listName}
            </span>
            {after}
          </p>
          <div className="flex flex-col-reverse gap-3 border-t border-dashboard-border pt-4 sm:flex-row">
            <button
              type="button"
              onClick={onNotNow}
              disabled={busy}
              className="min-h-[44px] flex-1 rounded-lg border border-white/[0.09] bg-transparent px-4 py-2.5 text-sm font-medium text-dashboard disabled:opacity-60"
            >
              {t("dashboard.wp2.nudge.notNow")}
            </button>
            <button
              type="button"
              onClick={() => void onPublish()}
              disabled={busy}
              className="flex min-h-[44px] flex-1 items-center justify-center gap-2 rounded-lg border-0 bg-[#60a5fa] px-4 py-2.5 text-sm font-semibold text-white disabled:opacity-60"
            >
              {busy ? <Loader2 size={14} className="animate-spin" aria-hidden="true" /> : <span aria-hidden="true">🌐</span>}
              {t("dashboard.wp2.nudge.publish")}
            </button>
          </div>
        </motion.div>
      </DialogPanel>
    </AnimatePresence>
  );
}

export default PublishNudge;
