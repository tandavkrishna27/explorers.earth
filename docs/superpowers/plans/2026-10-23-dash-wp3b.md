# WP3B List Page Template, Share/QR, Manage, Slug Redirects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One list page for the six non-Places categories with three tabs that are mounted once (Recommendations, Share, Manage), the publish pill top right, a working full-size QR download, editable slugs whose old URLs keep working, Archive (restorable) and permanent Delete, and drag-and-drop item reorder.

**Architecture:** New `features/shared/list/*` components take a small per-category adapter (`ListPageAdapter`) built from each category's existing query/command hooks, so the six `*ListView.tsx` files shrink to a wrapper each. Server work is limited to the commands the UI needs that do not exist on `main` (slug rename for every category, restore, permanent delete) and sits on top of the S1 redirect table from WP0 (migration 0066). No migration in this package.

**Tech Stack:** React 18 + TypeScript, Tailwind, framer-motion `Reorder` (already used by `components/reorder/ReorderableList.tsx`), `html-to-image` ^1.11.13, `qrcode.react` (`QRCodeSVG`, already used), Vitest + Testing Library; Express + `pg`, Vitest integration tests on Postgres 15; Playwright.

**Design source:** mocks v5 "List page" (pill top right, tab row with "＋ Add item" on Recommendations only, dashed add row, big empty CTA, phone bottom button on Recommendations only) and v3 "Sample list" (same list page structure). Scope LP-01, LP-03..LP-10, OWN-07, OWN-14, GL-06 (items). Design acceptance row "List page".

  async restoreCollection(accountId:string,id:string,expectedRevision:number,slug:string|undefined,key:string):Promise<CollectionRecord> {
    return this.command(accountId,'restoreCollection',{id,expectedRevision,slug},key,async db=>{
      const locked=await this.lockCollection(db,accountId,id,expectedRevision,{allowArchived:true});
      if(!locked.archived_at)throw new RecommendationFailure(409,'List is not archived');
      const next=slug??locked.slug;
      const taken=await db.query(`SELECT 1 FROM collections WHERE account_id=$1 AND category=$2 AND slug=$3 AND archived_at IS NULL AND id<>$4
        UNION ALL SELECT 1 FROM collection_slug_redirects WHERE account_id=$1 AND category=$2 AND old_slug=$3 AND collection_id<>$4 LIMIT 1`,[accountId,locked.category,next,id]);
      if(taken.rowCount)throw new RecommendationFailure(409,'List URL is taken; choose a new URL to restore');
      await db.query('UPDATE collections SET archived_at=NULL,slug=$2,revision=revision+1,updated_at=now() WHERE id=$1',[id,next]);
      return this.collectionRecord(db,accountId,id);
    });
  }

// utils/exportElementPng.ts
// QR cards render inside scaled modals and phones; capturing at the element's own layout
// size (offset*, unaffected by ancestor transforms) keeps the PNG complete (OWN-07).
export async function exportElementPng(element: HTMLElement | null, options: { backgroundColor?: string } = {}): Promise<string> {
  if (!element || !element.offsetWidth || !element.offsetHeight) throw new Error("QR card is not visible");
  const { toPng } = await import("html-to-image");
  return toPng(element, {
    cacheBust: true,
    width: element.offsetWidth,
    height: element.offsetHeight,
    pixelRatio: 2,
    ...(options.backgroundColor ? { backgroundColor: options.backgroundColor } : {}),
  });
}

export function savePng(dataUrl: string, fileName: string) {
  const link = document.createElement("a");
  link.href = dataUrl;
  link.download = fileName;
  link.click();
}

const PATTERN = /^[a-z0-9]+(?:-[a-z0-9]+)*$/; // must equal the contract's slug regex
const MAX = 80;                                // must equal the contract's max length

export const slugify = (text: string) =>
  text.normalize("NFD").replace(/\p{Diacritic}/gu, "").toLowerCase().replace(/[^a-z0-9]+/g, "-").replace(/^-+|-+$/g, "").slice(0, MAX);

export function slugProblem(slug: string): string | null {
