# WPCI: CI cycle-time Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut the time a code PR waits on its two required checks (`replatform-required`, `music-required`) from a typical 12-21 min to about 8 min, without removing, renaming, skipping or path-filtering any lane that feeds a required check.

**Architecture:** The measured cost is not the tests. In every slow run, most of the time goes to `npx playwright install --with-deps chromium`, whose `apt-get` step downloads about 26 MB of fonts from the Azure Ubuntu mirror at about 27 kB/s. The four PR e2e lanes in `ci.yml` move into the official Playwright container image, which already has the browsers and system packages. The `static` lane in `test.yml` drops `--with-deps`, because the runner image already has Chromium's shared libraries. A new script test pins the container tag to the locked Playwright version. Nothing else changes.

**Tech Stack:** GitHub Actions YAML, Playwright 1.61.1 (`mcr.microsoft.com/playwright:v1.61.1-noble`), Node 24.21.0, `node --test`, `gh` CLI.

**Parent plan:** `docs/superpowers/plans/2026-10-23-dashboard-phase.md`, section "WPCI". This plan replaces that section's candidate list after measurement (see "What changed from the parent plan").

## 3. What each required lane protects, and what this plan leaves alone

- **No required job is removed, renamed, path-filtered, sharded or made conditional.** Job keys and display names stay identical. They are pinned in `scripts/platform-release-authority.ts:43-67` (`CANDIDATE_CI_POLICY`) and `tunes/server/test/contracts/platform-release-authority.test.ts:25-31`. A matrix or shard would change the check-run names (`🎭 E2E Category B (1/2)`) and break that release authority.
- **Both aggregates keep their `if: always()` and their "every need must be `success`" logic.** A container that fails to pull fails the job (`failure`, not `skipped`), so the aggregate turns red. Task 6 proves this with a canary.
- **The docs-only skip (PR #139) is unchanged.** It is the only skip either aggregate accepts.
- **Workflow-level `paths` stays absent on `ci.yml` and `test.yml`.** This is pinned by `music-reconciliation-workflow.test.ts` ("keeps the documentation-reading contracts running…") and `replatform-workflow-authority.test.ts:53-60`.

### Task 2: Guard test (fails first)

**Files:**
- Create: `scripts/ci-playwright-image.test.cjs`

- [ ] **Step 1: Write the failing test**

```js
'use strict';
// Pins the PR e2e lanes to the official Playwright image whose tag equals the locked
// `playwright` version. A mismatch would make every lane download browsers again (or run
// a browser build the specs were not written against), and `--with-deps` would bring back
// the apt download that cost up to 16 minutes per lane (WPCI, 2026-10-23).
const test = require('node:test');
const assert = require('node:assert/strict');
const { readFileSync } = require('node:fs');
const { join } = require('node:path');
// js-yaml is what the tunes workflow contract tests already use (music-documentation-contract.test.ts:15);
// `static` installs tunes before it runs node --test.
const { load: parse } = require('../tunes/node_modules/js-yaml');

const root = join(__dirname, '..');
const workflow = parse(readFileSync(join(root, '.github/workflows/ci.yml'), 'utf8'));
const lock = JSON.parse(readFileSync(join(root, 'explorers-earth/package-lock.json'), 'utf8'));
const version = lock.packages['node_modules/playwright'].version;
const lanes = ['e2e-category-a', 'e2e-category-b', 'e2e-public-shell', 'e2e-music-account'];

test('every PR e2e lane runs in the Playwright image matching the lockfile', () => {
  for (const name of lanes) {
    const container = workflow.jobs[name].container;
    assert.ok(container, `${name} has no container`);
    assert.equal(container.image, `mcr.microsoft.com/playwright:v${version}-noble`, name);
    assert.equal(container.options, '--user 1001', name);
  }
});

test('no ci.yml job installs Playwright system packages with apt', () => {
  for (const [name, job] of Object.entries(workflow.jobs)) {
    for (const step of job.steps || []) {
      assert.doesNotMatch(String(step.run || ''), /--with-deps/, `${name}: ${step.name || step.run}`);
    }
  }
});
```

`js-yaml` is in `tunes/package-lock.json` (`node_modules/js-yaml`). After `npm ci --prefix tunes --legacy-peer-deps`, check it resolves: `node -e "require('./tunes/node_modules/js-yaml')"`.

| `npm ci --prefix ../tunes` inside the container needs a native build toolchain the image lacks | low (no `node-gyp`/`bcrypt` in tunes; `sharp` ships prebuilt binaries) | Task 5 runs it; on failure, add `build-essential` **only** if the failure is a native build, and re-measure |

| The random apt slowness was a passing mirror incident | possible | Then the saving is smaller but the variance is still removed; Task 5 measures the actual figure |
