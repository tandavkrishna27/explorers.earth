```

```

Baseline text: `try{harness.markProducerStage('initial-load');}catch{}`

**Two constraints this imposes on the fix.** `node.getText(ast)` for a function includes its entire body, and the seal hashes `trackGuideReads` and `assertOwnerCategoryReads` — so an `eslint-disable` comment placed *inside* either function breaks the hash gate exactly as the catch comments broke the regexes. Blast radius checked: `guides-native-diagnostic.test.ts` is the **only** seal whose regexes require an empty catch (`grep -rlE 'catch\\\{\\\}' scripts/*.mjs tunes/server/test/contracts/*.ts`). The other specs' seals compare printed AST, which is why they pass with the annotations in place.

# Task 2: Opt-in stderr for the Windows helper

**Files:**
- Modify: `tunes/scripts/music-local-state.ts` (`runLocalProcess`, ~line 20-32)
- Modify: `.github/workflows/music-c0-contracts.yml` (Windows-only step env)

Diagnosis has stalled because the only remaining signal is the child's stderr, which is discarded on purpose: *"External stderr may contain credentials or raw system errors. Never retain it."* That default stays. This adds an explicitly opt-in capture, off unless asked for.

- [ ] **Step 1: Capture stderr only when the flag is set**

In `runLocalProcess`, replace:

```ts
    // External stderr may contain credentials or raw system errors. Never retain it.
    child.stderr.resume();
```

with:

```ts
    // External stderr may contain credentials or raw system errors, so it is NEVER retained by
    // default. MUSIC_LOCAL_STATE_STDERR is an explicit, opt-in diagnostic used only by the
    // Windows CI leg, where the helper exits non-zero with empty stdout and no other signal
    // survives. It prints to this process's stderr and is never returned to callers or stored.
    let diagnostic = '';
    if (process.env.MUSIC_LOCAL_STATE_STDERR === '1') {
      child.stderr.on('data', (data: Buffer) => { if (diagnostic.length < 4096) diagnostic += data.toString('utf8'); });
      child.on('close', () => { if (diagnostic.trim()) console.error(`[music-local-state stderr] ${executable} ${args.at(-1) ?? ''}: ${diagnostic.trim().slice(0, 4096)}`); });
    } else child.stderr.resume();
```
